# Legacy Classroom Retirement

Microsoft Teams is the canonical live-class provider for student and lecturer UI.

Legacy Jitsi/JaaS code remains temporarily in the repository for rollback/reference only and is not routed from the canonical Live Classroom navigation. Do not create new JaaS sessions.

Removal gate: after Teams production pilot verifies meeting creation, student joining, moderator controls, whiteboard, recording, transcript, attendance and artifact ingestion, delete legacy Jitsi/JaaS UI/functions/config and old classroom tables through a separately reviewed migration.

Lecturers do not perform summative marking from their navigation; specialist marker/assessor workflows own summative assessment.
