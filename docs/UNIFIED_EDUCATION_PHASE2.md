# Unified Education Phase 2

This phase turns the unified catalogue into operational transactions.

## Enrolment
Student selects course/cohort -> eligibility snapshot -> funding/payment route -> admissions decision -> enrolled. Fee and eligibility snapshots preserve what the learner was shown at application time.

## Employer Academy
Corporate account -> course offer -> seat allocation -> employee invitation -> enrolment -> learning/attendance -> assessment -> completion -> HR report. Employee learning data is restricted to the agreed corporate reporting scope.

## Tuition
Guardian/student selects board/grade/subjects -> subscription/package -> timetable -> teaching/homework/quizzes/mocks -> progress snapshot -> guardian dashboard. Safeguarding controls remain mandatory for minors.

## Vocational practical
Course competency -> practical partner -> dated hours/evidence -> supervisor sign-off -> qualified assessor -> competent / not yet competent / more evidence required. Partner sign-off never substitutes for the required formal assessor/QAB process.

## Next gates
Wire payment provider to course/cohort checkout; add corporate bulk CSV invitation; add practical evidence upload; build Course Factory admin; add notification events; regenerate Supabase TS types; RLS/E2E tests before production deployment.
