# Virtual Lab Phase 2

Provider configuration is tenant-scoped and credentials remain in deployment secret storage, never database metadata/client code. A provider is not launchable until explicitly enabled.

Class runs bind a lab template to cohort, Teams/live class, lead instructor and TAs. Large cohorts can be divided operationally across TA support while retaining one class run/help queue.

Cost policy: education/free entitlement first; then low-cost container/Jupyter; student credits; on-demand VM; specialist managed lab. Each session records minutes, estimated cost and idle-shutdown policy.

Evidence stores deterministic task verification and practical evidence references. Instructor sign-off is distinct from automated verification. Observe/assist/control remains audited.

Production provider work still requires official credentials/API contracts for GitHub/AWS/Azure/managed lab providers. Do not invent endpoints or expose provider tokens to students.
