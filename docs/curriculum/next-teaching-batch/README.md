## From draft to course

1. The programme lead records the exact destination programme, module, approved specification and version. Do not map by a similar title, and do not create a new live module to make an unmatched lesson fit.
2. The lecturer checks terminology, examples, accessibility and level, then previews the lesson as a learner. Adapt the activity for the actual delivery mode; avoid assuming every planned minute is guided learning.
3. Keep original practice distinct from formal coursework and exam materials. The assessor and internal quality assurer review any proposed assessed use separately. Do not add copied exam content, real learner records or real visa documents.
4. When the lead approves the mapping, save the content as an unpublished lesson draft in the assigned module. Verify the preview, order and access. Release only after programme and access approvals. This repository batch does not upload or publish anything to the learning platform.
