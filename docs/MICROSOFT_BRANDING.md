# Microsoft Branding for UniPathway

Microsoft can carry UniPathway branding, but not every Microsoft surface is fully white-label.

## Entra / Microsoft 365 sign-in
Configure institutional sign-in with UniPathway banner/square logo, background image/color, favicon, sign-in title/text, help/privacy/terms links where supported. Microsoft Entra licensing/tenant prerequisites apply.

## Teams meetings
Teams Premium meeting themes can apply organization logo, brand image and color to supported pre-join/lobby/invite/meeting surfaces. Only organizers with the required Teams Premium licence can create themed meetings, but participants can see the theme without Premium. Teams Premium can also distribute organizational video backgrounds.

Recommended licensing: do not buy Premium for every student. Assign it to the smaller organiser/lecturer/event-organiser pool where branding/event features justify it.

## UniPathway LMS wrapper
The strongest branding remains our own LMS: branded class card, countdown, lecturer/moderator, Join Live, resources, persistent whiteboard, attendance, recording/transcript and lesson pack. Teams handles media; UniPathway owns the education experience.

## Class templates
Tutorial 1-20: full interaction + whiteboard.
Seminar/workshop 20-50: interaction + breakouts.
Lecture 50-300+: attendee mic/camera off, moderator, Q&A/polls.
Webinar/town hall: controlled large event according to licensed Microsoft capacity.

## Brand assets required
Square logo light/dark, horizontal/banner logo, 1920x1080 sign-in image, meeting theme image, lecturer background, event background, primary brand hex, help/privacy/terms URLs. Keep Microsoft asset size/format requirements in the deployment checklist and regenerate assets if Microsoft changes them.
