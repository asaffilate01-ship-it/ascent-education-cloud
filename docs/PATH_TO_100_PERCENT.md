# Path to 100%

100% is an evidence state, not a development estimate. A required gate is passed only after its test/approval/integration has evidence.

## Can be completed in code/repository
Green CI, migration replay tooling, generated types, RLS/IDOR tests, storage tests, Edge Function audit, authenticated E2E, monitoring hooks, backup/restore runbook, event wiring, RAG permission tests, integration-health probes, native project scaffolding and load-test harness.

## Requires external accounts/decisions
Central Omniqora Factory endpoint/credentials; Microsoft Education tenant/Graph/admin consent/licences; authorised NADRA onboarding or formally approved manual fallback; payment/bank/wallet production credentials; lab provider education accounts/APIs; STEMCoach API/SSO access; Apple/Google developer/signing accounts.

## Requires academic/operational evidence
Actual awarding-body approvals/status, approved launch course materials, trained/vetted staff and markers/IQA, safeguarding/privacy/CCTV policies, partner placement agreements, emergency/centre SOPs and pilot evidence.

Do not change a gate to passed merely because an integration stub or UI exists.
