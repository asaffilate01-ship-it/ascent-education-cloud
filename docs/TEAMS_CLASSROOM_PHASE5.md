# Teams Classroom Phase 5

## Calendar
Every approved live session should sync to the lecturer, moderators and enrolled students' institutional Microsoft calendars after Graph credentials are enabled. Sync state/errors are retained per user/session.

## Account activation
Student admission/enrolment -> institutional account requested -> licence/mailbox/Teams readiness -> secure initial sign-in/password process -> MFA -> terms -> complete. Do not store Microsoft passwords in UniPathway.

## Notifications
Configurable class reminders can create in-app and institutional-email events, e.g. 24 hours and 30 minutes before class, class changed/cancelled, recording ready and lesson pack published.

## Lesson packs
AI-generated content stays draft until academic review. Students only see published/approved packs. Packs expose summary, concepts, glossary, revision questions and quiz alongside original recording/transcript/whiteboard artifacts.

## Remaining production integration
Microsoft Graph meeting/calendar creation; change-notification subscriptions for transcripts/recordings; attendance ingestion; secure artifact retrieval; account/licence provisioning; webhook validation; retention/deletion; RLS/E2E/load testing.
