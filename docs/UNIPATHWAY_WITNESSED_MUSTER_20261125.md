# Witnessed emergency accountability — controlled extension

Builds on the reviewed physical site operations release. A trained security officer records a drill or already reported emergency and explicitly attests that the physical procedure is in use. The transaction snapshots only people recorded inside by the existing occupancy register; no automatic safe marks, complete headcount, alarm operation or door command. A witnessed roll-call records identity-checked safety at a real assembly point; corrections retain append-only operator audit. The administrative closure is a separate centre director or selected-centre owner decision, requires a responsible official's reference and unresolved-person handover, and preserves the unresolved count. It is never an all-clear, permission to re-enter, emergency response or compliance certification.

The new SQL candidate depends on the installed, accepted site operations schema. The backend site and muster writes remain disabled until independent acceptance, and the UI requires VITE_UNIPATHWAY_SITE_OPERATIONS_ENABLED and VITE_UNIPATHWAY_WITNESSED_MUSTER_ENABLED. The server verifies exact centre scope, private RLS/grants, role membership, idempotent requests, stale revisions, independent closure and a single recorded active incident. Real-world missed scans, visitors absent from the register, unrecorded occupancy and unmatched records remain limitations; use physical roll-call, evacuation procedures and emergency services first. Do not delay evacuation or return to the building to use a screen. No invented floor plan, automatic notification, live provider event, or production activation.
